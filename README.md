# 📖 About

**School Portal ASP.NET** is an ASP.NET school desk.

It covers the daily records of a school: classes, lessons, student profiles, marks, and a search page. Shared layout lives in the master pages. The solution file opens the site in Visual Studio.

> **Tagline:** *An ASP.NET school portal for classes, lessons, students, and marks.*

This is a school site sample. It is separate from the PHP desk in [Student Portal](https://github.com/sadra-hatami/Student-Portal).

---

# 🚀 Why This Project?

A school desk needs more than a student list.

This site keeps the pieces on their own pages:

- Classes and lessons
- Student profile pages
- Mark entry and mark edit
- Search across the records

The master pages keep the layout in one place.

# ▶️ How to Open

1. Clone the repository.
2. Open `Source.sln` in Visual Studio.
3. Set `Default.aspx` as the start page.
4. Run the site.

Connection settings live in `web.config`. Point them at a local database before a public run. Do not commit `.mdf`, `.ldf`, or `.bak` files.
